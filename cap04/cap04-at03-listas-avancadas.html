Seção 2 — Ranking de Tecnologias

  1. HTML

    Linguagem de marcação responsável pela estrutura das páginas web.

  2. CSS

    Utilizado para estilização visual e responsividade das interfaces.

  3. JavaScript

    Linguagem que adiciona interatividade e dinamismo às aplicações web.

  4. React

    Biblioteca JavaScript amplamente utilizada para construção de interfaces modernas.

  5. Node.js

    Ambiente de execução JavaScript voltado ao desenvolvimento backend.

Seção 3 — Glossário de Termos Técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Linguagem responsável pela estilização visual de páginas web.
JavaScript
Linguagem de programação usada para adicionar interatividade.
DOM
Estrutura em árvore que representa os elementos de uma página HTML.
Interface que permite manipular elementos da página via JavaScript.
API
Conjunto de regras que permite comunicação entre sistemas.
Pode disponibilizar dados e serviços para aplicações externas.
HTTP
Protocolo HTTP
Protocolo utilizado para transferência de dados na web.
URL
Endereço Web
Localizador utilizado para acessar recursos na internet.
DNS
Sistema responsável por traduzir nomes de domínio em endereços IP.
